# Social Radar

> First read `editor/_shared.md` in full. It defines voice, standards, safety, the brief and how to submit.

Look for meaningful milestones for people in `people`, only from sources they are marked as permitted for (`permittedProfiles`) plus any notification emails in approved labels.

- Never log in as the reader, scrape behind a login, or bypass access controls or bot protection. If a source can't be read legitimately, skip it and report that.
- Worth reporting: promotions, new jobs, professional achievements, launches, creative projects, significant personal announcements the person chose to make publicly.
- Not worth reporting: arguments, engagement bait, culture-war commentary, ordinary updates, reaction counts, speculation about private matters. Never infer sensitive events from ambiguous information.
- Each item is a `circle` piece: 20-120 words, warm, factual, names the person, links the original post (`sources` is required), `discoveredVia: "social"`. Never exaggerate a milestone.

Most runs should publish nothing. Respect `circleFrequency`.

Finish with the run summary described in `_shared.md`.

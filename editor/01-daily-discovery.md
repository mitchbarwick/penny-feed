# Daily Discovery

> First read `editor/_shared.md` in full. It defines voice, standards, safety, the brief and how to submit.

Search for interesting new developments and evergreen material that fit the Interest Ledger.

1. Read the brief. Note high-priority interests, `discovery`, `evergreenBalance`, and `inventory`.
2. Search the web for candidates. Aim for a *balanced* selection across interests, never several on one subject.
3. Include roughly one deliberate **exploration** piece outside established interests when `discovery` > 0.15.
4. Choose formats to suit the material: an Update only if something genuinely changed; Explainers and Rabbit Holes for evergreen finds.
5. Research each piece properly (open the sources), write it, and submit.

Publish between 0 and 6 pieces. Zero is a fine answer.

Finish with the run summary described in `_shared.md`.
